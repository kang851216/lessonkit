Random student picker ideas that keep the classroom calm

Calling on whoever raises a hand brings the same students to the front. Calling in roll order makes the sequence easy to guess. A name wheel fixes both, if it is used with clear rules.

Six ways to use a random student picker

  • Answering a question. Spin, and the student who comes up answers one question.
  • Presentation order. Every name is on the wheel; the spin decides who presents first.
  • Cleanup duty. Faster than a rota and nobody can argue with it.
  • Daily group leader. Leadership rotates without an election.
  • Quick quiz. The student who comes up picks a 1-point or a 2-point question.
  • Lesson wrap-up. One spin to choose who sums up today's lesson.

Four rules so nobody feels embarrassed

  1. Say the rule before the spin. “Every name is on the wheel, so anyone can come up.”
  2. Give thinking time, not a surprise. Announce that the wheel will be used, then spin, so students can prepare.
  3. Allow one pass. A student may skip one turn but stays on the wheel for the next round.
  4. Never use it as a punishment. If the wheel is used to tell students off, they will fear the tool instead of the rule.

Use remove-winner mode for long sessions

To call on every student once in a lesson, turn on the Remove winner option in the name picker wheel. A name that has come up leaves the wheel, so nobody is called twice before everyone has had a turn.

Save the name list once

The list is stored in the browser, so you don't retype it each day. On a shared classroom computer, remember it is saved only in that browser.

Share the result

When the wheel stops, press Share result to create an image of the winner. Send it to the class group chat as proof the pick was random — that removes almost every complaint.
