Name wheel for groups: splitting students without favoritism

Teachers often use a name wheel to pick one student, then get stuck when the class has to be split into groups. Those are two different jobs: a wheel picks one name, a group maker splits the whole list at once. This page explains when to use which, and puts both in the same place.

The most common mistake is spinning the wheel again and again to build groups. That is slow, and the result is often uneven because the leftover names pile up in the last group.

How to split a class into balanced groups

  1. Paste the whole list of names once, one name per line.
  2. Choose the number of groups — 4 for a class of 32, for example, or 6 for a class of 36.
  3. Choose roles if the groups need structure: Chair, Note-taker, Spokesperson. Roles are assigned at random, not appointed.
  4. Save the result as an image or a CSV file so you can stick it on the board or send it to the class chat.

Keeping groups from always being the same

A fresh random split every lesson is fair, but it can separate students who help each other. Many teachers use a mixed pattern: random groups for a new task, then a rotation between groups for a long project. What matters is that the decision is still announced as the result of a draw — not as the teacher's choice.

Odd-sized groups

A class of 33 split into 4 groups gives 8, 8, 8, and 9. A difference of one student does not matter for discussion work, but if the activity needs equal numbers, the extra student can be pulled out into a small observer group.

Ideal group size by type of activity

ActivityIdeal sizeExample for a class of 32
Short discussion4–5 students6 to 8 groups
Two-week project4 students8 groups
Lab work2–3 students11 to 16 groups
Class debate6 students5 groups

Small groups get every student talking; large groups finish faster but usually only two people do the work. For a class of 32, four to six groups is the balance point between the two.

When some students are absent

Recount the list for that day instead of reusing last week's groups. Splitting again with this tool takes under a minute, while reusing the old groups leaves some of them over-full when a student is away — and that usually only shows up once the activity has started.

Frequently asked questions

How many groups can I make?

Between 2 and 10. For a class of 30–40 students, 4 to 6 groups is usually the most comfortable for discussion.

Can the result be saved?

Yes. It can be downloaded as a PNG image to stick on the board, or as a CSV file to open in Excel.

Can students choose their own group?

No, and that is deliberate. A random split stops groups forming along friendship lines, which often leaves particular students on the outside.
